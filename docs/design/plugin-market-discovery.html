素材现状（本仓实测，2026-10-08）

索引 18 个插件里，只有 6 个带截图、6 个带 icon（且是同一批），其余 12 个什么都没有。截图比例从 3600×740（Token 速度表，一条状态栏）到 357×425（AI 配额，竖屏）不等。

所以轮播位不能默认「一张能裁切的图」：直接用截图 cover 满铺会糊（点“真图·满铺”能直接看到）。两条路：编辑在 featured.json 里补一张 16:9 封面，或者像本稿这样让截图按原比例自成一张卡（截图 → icon → 渐变块三级回落）。

如果让我选

先上 B（偶发一屏就能讲完），数据结构一次定成 C 的超集。 featured.json 同时带 spotlight[]（有序）与 collections[]（分组）： B 只读 spotlight；A 只读 spotlight 并加轮播；C 读 collections 并支持 hero: true 的合集排在最前。 三种形态同一份数据，换 UI 不用改契约。
